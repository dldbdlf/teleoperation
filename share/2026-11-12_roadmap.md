# 2026-11-12_roadmap — Jetson 전용 30분 AprilTag/카메라 오차 개선 실험

> **작성일:** 2026-11-12 (목, KST) · **상태:** PLANNED — 아래 측정은 아직 실행하지 않은 실험 예정 사항
>
> **범위:** NVIDIA Jetson AGX Orin + 연결된 RealSense 카메라 / 기존 AprilTag GT rig. **Rokoko 장갑, Windows PC, Rokoko Studio, FBX, 라이브 스트리밍 일절 필요 없음.**
>
> **고정 연구 원칙:** 온라인 Teleoperation 입력은 **D415 단일 RGB-D**. D435i와 AprilTag는 이번 30분 동안 **GT·캘리브레이션 측정용**으로만 허용하며 Solver/Markerless Pose 입력에 넣지 않는다. 두 카메라가 연결되지 않거나 사람이 Tag를 착용할 수 없으면 아래 **대체 경로**를 실행한다.
>
> **연결 자료:** [11/10 측정 로그](11.10_exp/report.txt) · [AprilTag GT rig](apriltag_gt/README.md) · [EX00–EX10 로드맵](docs/experiment_roadmap.md) · [11/05 Gazebo 로그](11.05_exp/README.md)
>
> **이번 목표는 신뢰 가능한 GT를 만들기 위한 오차 원인 분리 및 재측정이다.** 기존 E(T1)-E(T2) 불일치가 110–130 mm → 실제로 얼마가 되는지 확인하기 전에는 GT 정확도 개선을 주장하지 않는다.

## 2. 정확히 30분 실행 순서 (Jetson, 장갑 불필요)

|---|---|---|---|
| **00–03** | **P0 안전·버전 확인** | Jetson `git status`, `main` 동기화 여부, `compute_joint_centers.py` 실제 로딩 YAML 경로, D415/D435i topic 연결 확인 | 구버전 로컬 파일·stale calibration이면 측정보다 먼저 수정 |
| **03–07** | **P1 Tag 치수·좌표 규약 확인** | T0=9, T1=6, T2=6, T3=4 cm가 *실제 검은 사각형 실측값*인지 확인. `mount_sign: -1` 실제 T2 장착과 일치하는지 확인. T1/T2 피부 부착 흔들림과 Tag 면 방향 점검 | 물리 크기 불일치/자세마다 Tag 흔들림 발견 시 오차 원인을 기록하고 수치 GT 판정 보류 |

| **22–27** | **P4 독립 거리·시간 검증** | 카메라로부터 여러 거리에 둔 **길이 알려진 정적 기준물**의 PnP/역투영 거리 오차를 자 측정과 비교. D415/D435i 두 카메라의 타임스탬프 skew 기록. 가능하면 전반부·후반부 extrinsic 차이 재확인 | 반복성만이 아니라 실제 scale/bias 검증. 기준 거리 미측정이면 G0 보류 |

**30분 우선순위:** P0 → P1 → **P3 팔꿈치 교차검증** → P2 Extrinsic → P4. 일정이 밀리면 P4는 후속 실험으로 넘기되, 측정이 부족한데 PASS 처리하지 않는다. P0/P1과 P3를 완료하는 것이 최우선이다.

## 4. P2 — Extrinsic 오차 줄이기: 반복성과 정확도의 구별

**과거 문제:** 11/10 1차는 마커를 빠르게 움직여 z std=33.7 mm, 2차는 천천히 정지하여 z std=14.2 mm였다. 시야각/거리·blur·동기화 차이가 섞였을 수 있다. 태그 크기·SolvePnP 회전 흔들림도 주요 원인 후보.

**이번 절차**
1. 실제 T0 검은 정사각형 한 변을 mm 단위로 측정하고 `--tag-length-m`에 전달한다. 9 cm는 확인된 경우만 입력.
2. D415/D435i 고정, 두 카메라에서 **같은 Tag ID 0**이 보이는지 확인. 두 optical frame의 parent/child 방향을 명시한다.
3. 기준 Tag를 움직이는 순간이 아니라 정지시킨 후 60쌍을 수집한다. 기존 코드는 수집한 pose에 대해 평균·std만 계산하며, blur/reprojection score rejection 로직은 없으므로 이번 단계에서는 프레임 상태를 직접 확인하고 **코드에 아직 없는 자동 검증 기능을 있다고 가정하지 않는다**.
4. 가능하면 여러 위치·각도에서 짧은 정지 구간을 반복하고 구간별 분산과 전체 분산을 나눠 기록한다. 한 자세만 측정하면 특정 view의 편향을 보지 못한다.
5. `ApproximateTimeSynchronizer`의 현재 허용 `slop=0.05 s`(50 ms)가 움직이는 Tag에서 좌표 차이를 만들 수 있다. 원시 `header.stamp` 차이와 수집 비율을 기록한다. 시간 조건 조정은 측정된 FPS/드롭률을 보고 결정한다.
6. 독립적 길이 또는 자로 잰 카메라 기선·기준물의 변환 후 3D 위치를 비교해 **bias/scale** 확인. 표준편차 개선만으로 절대 정밀도가 좋아졌다고 주장하지 않는다.

```bash
# 각 RealSense ROS 노드가 이미 실행 중이어야 함
ros2 topic list | grep -E 'cam_[12]|camera_info'
ros2 topic hz /cam_1/D415/color/image_raw
ros2 topic hz /cam_2/D435i/color/image_raw
# Tag 실제 크기가 0.09m인 경우에만 사용
cd ~/teleoperation_repo/share/apriltag_gt
python3 extrinsic_calib_apriltag.py --tag-id 0 --tag-length-m 0.09 --n-samples 60
```

**제안하는 초기 엔지니어링 목표(학회 공식 기준 아님):** Extrinsic translation 표준편차 벡터 크기 ≤ **5 mm** (미달이어도 자세·거리별 원인 분석), 독립 기준물 3D 거리 오차 median ≤ **10 mm**. 독립 기준물 측정이 없으면 GT 정확도 Gate G0는 **판정 불가**.

## 5. P3 — 팔꿈치 중심 110–130 mm 오차 줄이기

**이미 코드에서 수정된 두 요소 (PR #11):**
- `depth_cm` 값이 *둘레/2*이므로, 반지름 근사 `depth_cm / pi`를 사용한다. 상완 16 cm → 5.1 cm, 전완 14 cm → 4.5 cm.
- Tag 크기가 최초 출력 7.1/4.8/4.8/3.2 cm에서 재인쇄 9/6/6/4 cm로 바뀌었다. 실제 부착물과 설정을 일치시킨다.

**측정**
1. 신체에 부착된 T1/T2의 ID, Tag의 위쪽(+y), 표면 바깥쪽(+z), T2의 `mount_sign=-1`이 실제 정합되는지 확인한다.
2. 팔꿈치 중심 E를 상완 Tag와 전완 Tag에서 **독립적으로** 계산해 동일한 D435i camera optical frame에서 비교한다.
3. 중간 굽힘 포함 3개 정지 자세마다 동시 관측 유효 프레임을 여러 개 기록한다. `E(T1)-E(T2)`의 3축 분해값, 3D norm, median/P95, Tag 관측 누락을 기록한다.
4. 두 Tag 오차가 큰 경우 offset 길이, Tag 면과 실제 뼈축 회전 오차, 피부 미끄러짐, T2 sign, D435i intrinsics/Tag size 문제를 구분한다. 한 자세에서만 두 좌표를 맞추도록 보정하면 다른 자세에서 악화될 수 있다.
5. 정밀 GT 확립을 위해서는 여러 자세의 공통 팔꿈치 중심을 제약으로 **joint center offset을 추정(least-squares / robust fitting)**하고, 별도의 보류 자세로 검증하는 후속 단계가 필요하다. 둘레/π 원통 근사는 provisional 초기값이다.
6. T0 가슴 Tag와 어깨 중심 S는 몸통을 원형으로 둔 잘못된 근사일 수 있다. GT로 확정하지 말고 별도 functional calibration으로 검증한다.

```bash
cd ~/teleoperation_repo/share/apriltag_gt
python3 compute_joint_centers.py --rate 5
# 로그의 E cross-check |T1-T2|=... mm을 각 자세에 대해 기록
# /gt_overlay/image는 시각적 점검용이며 오차 정답을 의미하지 않음
```

**제안하는 초기 엔지니어링 목표:** E(T1)-E(T2) 불일치 median ≤ **20 mm**, P95 ≤ **30 mm**. 여기 도달하더라도 **독립 기준 없이는 관절 중심의 절대 오차가 20 mm 이하라고 결론 낼 수 없다.** 이 기준은 초기 GT rig 개선 판정용이며 최종 정밀 GT 인증이 아니다.

## 6. 대체 경로: 30분 안에 못 하는 조건이 있을 때

- **장갑 없음:** 영향 없음. Rokoko/FBX/Windows 작업은 아예 실행하지 않는다.
- **사람이 Tag를 착용할 수 없음:** P0·P1·P2만 실행. 정적 Tag와 자/알려진 물체로 카메라 및 Pose scale 검증. P3 관절 GT는 **BLOCKED**.
- **D435i가 없거나 두 카메라 동시 가동 불가:** D415만으로 Tag 6D pose 반복성·3D known-length test 수행. D415↔D435i Extrinsic은 **BLOCKED**, 수치를 임의 작성하지 않는다.
- **Tag가 하나만 보임:** 보이는 Tag의 reprojection / pose repeatability만 계측. T1/T2 동시 팔꿈치 교차검증은 미실행 처리한다.
- **코드 버전 또는 실제 로컬 YAML 불명:** 측정값을 논문 GT로 사용하지 말고 config SHA와 실제 읽은 경로부터 기록한다.
- **잔여 시간이 짧으면:** 새 Solver 구현·제어 연결보다 GT 좌표계 오류/치수 일치와 P3 재측정을 우선한다.

**판정**
- **PASS (예비 반복성/정합 Gate):** 로컬 보정값 동기화 확인, 다자세 E 일치와 정적 extrinsic의 수치 목표 충족, 독립 기준물 확인. 실제 GT 용도로의 최종 인증은 별도 실험.
- **PARTIAL:** 새 코드 적용 및 일부 측정 성공하지만 목표 미달 또는 독립 기준물/동시 Tag 관측 부족.
- **BLOCKED:** 카메라/Tag 미확보·부착 문제·측정 스크립트 오류·좌표계 미확인. 누락값을 0으로 채우지 않는다.

**원시 인간 영상/장갑/얼굴 등 개인 식별 자료는 GitHub에 업로드하지 않는다.** 로그에서 비밀정보·개인경로·피험자 식별정보를 제외한 요약만 `share/11.12_exp/report.md`에 추가한다. 원시 센서 파일은 접근 제어된 로컬 위치에 둔다.

## 8. 30분 이후 (이번 세션 범위 밖)

1. Tag↔관절 중심 offset을 다자세 robust least squares로 보정하고, 보류 자세로 검증. Markers가 보이지 않는 프레임은 `gt_valid=false`.
2. D415 RGB-D의 **Markerless S/E/W**와 GT-valid subset을 비교하고 3D MAE/P90, ψ circular MAE/P90, 보임/가림 분할 지표 산출. Tag/GT 외형이 online 모델 입력에 새지 않도록 GT와 온라인 경로 분리.
3. Solver Track EX04는 별도 PC/시간에 S1–S6, B0–B8을 같은 synthetic 데이터에 실행하고 Feasible-MAP P 구현 후 G1 평가. 현재 B7 계산시간 P95 약 78 ms(기존 PR 결과)는 15 Hz 관측 주기 약 66.7 ms를 초과하므로 지연 최적화가 필요. **이 수치와 카메라 GT 오차는 다른 문제다.**
4. NERO/Gazebo의 과거 최대 관절 추종 오차 0.0259 rad는 추후 별도 closed-loop 시험에서 측정. 오늘의 camera GT Gate와 혼합하지 않는다.

> **실험은 여기서 수행되지 않았다. 본 파일은 Jetson 운영자가 즉시 실행할 수 있는 30분간의 사전 프로토콜만 기록한다.**
