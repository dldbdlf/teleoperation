2. D415 <-> D435i extrinsic 재측정 (AprilTag 기반)
---------------------------------------------------------------------
- 11/3 ArUco 기반 결과(z std 44.7mm, GT로 쓰기엔 불충분 판정)를 AprilTag로 재시도

태그 크기 혼선:
- 처음엔 실측값(7.1/4.8/4.8/3.2cm)으로 시작
- 이후 추천 nominal 크기(9/6/6/4cm)로 재인쇄, 아직 자로 재확인은 안 함(T1-T3는 특히)

중간 실수: 카메라가 T0(ID=0) 아닌 T1(ID=1)을 보고 있던 걸 스냅샷으로 확인 후 수정
(rqt_image_view로 양쪽 카메라 실시간 화면 띄워서 이후엔 바로 확인 가능하게 함)

측정 결과 (T0, 9cm, n=60 샘플):
  1차 시도 (태그를 빠르게 움직임, ~22초만에 60개 수집)
    translation std: [17.5, 16.6, 33.7] mm, 전체 std 크기 41.5mm
  2차 시도 (태그를 천천히, 각 위치 1-2초 정지)
    translation std: [6.9, 8.8, 14.2] mm, 전체 std 크기 18.1mm  <- 최종 채택

  11/3 (44.7mm z std) -> 11/10 2차 (14.2mm z std)로 개선됐으나,
  로드맵 G0 기준(독립 ruler/rig 검증)은 아직 미통과 - 반복성만 확인된 상태.

최종 변환:
  translation (m): [-0.47115, 0.01617, 0.56663]
  ros2 run tf2_ros static_transform_publisher -0.47115 0.01617 0.56663
    0.00020 0.70309 -0.00907 0.71104 D415_color_optical_frame D435i_color_optical_frame

6. 태그 -> 관절중심(S/E/W) 오프셋 실측 + D4용 추정 스크립트
---------------------------------------------------------------------
- tag_joint_offsets.yaml 템플릿 작성 (along_bone_cm, depth_cm 측정 가이드 포함)
- 사용자가 자로 실측: T0->S 25cm, T1->S/E 17/17cm, T2->E/W 14/15cm, T3->W 6cm
  (depth_cm은 각 부위 둘레/2)
- compute_joint_centers.py 작성: D435i 라이브 피드에서 태그 pose + 오프셋으로
  S/E/W 좌표 실시간 추정, 오버레이를 /gt_overlay/image로 퍼블리시해서 시각 확인
- 버그 발견/수정: T0 yaml 구조(depth_cm이 to_shoulder_S 안에 중첩)때문에 크래시
  -> 코드 수정으로 해결
- T1 vs T2로 각각 구한 팔꿈치(E) 교차검증 오차가 ~190-220mm로 큼 발견
  -> T2(전완) 태그가 뒤집혀 부착된 것으로 판단, mount_sign: -1 보정 추가
  -> 교차검증 오차 ~110-130mm로 개선 (재부착 없이 소프트웨어로 해결)
  -> 남은 오차는 자 측정 정밀도/태그-뼈축 정렬 오차로 추정, 이 단계에선 수용 가능
