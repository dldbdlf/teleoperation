2026-11-15 NERO 7-DoF — 확률적 관절 분포 / IK branch tracking 탐색 실험

결론: PARTIAL — Branch-Aware Tracking의 이점은 재현되었지만, 확률 분포 추가의
독립적/일관된 이점은 아직 입증되지 않았다.

[중요: 근거 범위]
- 이 결과는 GitHub main의 NERO URDF 기하와 해석적 IK 기반으로 수행한
  새로운 *소규모 통제 합성 실험*이다.
- 기존 EX04 894 trajectory의 재실행이 아니다. 기존 Jetson의 로컬 P/Pc 구현,
  실측 D415 영상, learned belief, 충돌 검증을 사용하지 않았다.
- 여기의 E0~E3를 기존 보고서의 B7/P/Pc 성능이라고 부르면 안 된다.
- 실행 위치: 이 작업 세션의 CPU Python 환경, Jetson 아님.
- 소스: share/sim/experiments/prob_joint/{nero_kin.py,run_experiment.py}
- 기존 루트 result.txt는 변경하지 않았다.

[실험 구성]
- 모델: AGILEX NERO 7-DoF의 URDF에서 추출한 joint origin/limit 및
  해당 저장소 share/sim/kinematics.py의 analytic SEW IK.
- 기초 IK 테스트: 범위 내 난수 관절각 30개 중 30개에서 feasible IK 해 발견.
  IK -> FK 자세 행렬 최대 노름 오차 3.16e-7 (단위 혼합 행렬 Frobenius norm).
- 같은 조건의 합성 episode 60개/조건. Episode당 카메라 프레임 72개,
  합계 4,320 프레임/조건, 약 4.8초/episode.
- 각 episode의 손목 목표 SE(3)는 고정, 팔꿈치 psi 의도만 시간에 따라 변화.
  가림은 프레임 24~41 사이(18 frames, 약 1.2초).
- 가시 psi noise Gaussian sigma 11도, 가림 중 sigma 65도 및 random drift.
- 매 관측 프레임에 고정된 psi grid(10/15/20도)를 따라 실제 feasible IK
  다중 branch를 enumerating; 모든 방법에 같은 후보/관측/초기 q/속도제약.
- 15Hz 관측, 100Hz q_cmd 시뮬레이터, joint speed cap pi rad/s.
- 고정한 pseudo-random seed: 9131~9190.
- E0: 단일 canonical MAP IK를 그대로 목표로 추종
- E1: 동일 canonical q_ref + 현재 q에 대한 고정 continuity penalty로 branch-aware tracking
- E2: IK 후보들에 대한 categorical joint probability(softmax log likelihood + home prior)
      와 entropy-adaptive continuity penalty를 적용한 단일 프레임 tracking
- E3: 관절 후보 상태의 Markov 전이 posterior를 시간적으로 filtering하는 tracking
- E1/E2/E3 모두 E0와 똑같은 deterministic q_ref를 별도로 계산/보존함.
  각 episode의 동일 belief 100회 반복 시 q_ref 최대 차이 0 rad.
  그러나 이 검증은 단일 프로세스/사전 계산된 후보집합에 한정됨.

[중요한 한계/실제 시스템과의 차이]
1. Tool pose 고정, human psi만 변화: 실제 wrist trajectory, RGB-D, wrist occlusion,
   깊이 오차, 관측 누락의 정확도와 latency를 대표하지 않음.
2. 실제 관절 역학, 자기충돌, 물체 충돌, actuator 응답 및 joint acceleration safety 없음.
   joint velocity cap만 검증.
3. 조인트 분포는 IK 후보에 대한 heuristic categorical probability. 실제 posterior
   calibration/NLL/coverage는 측정하지 않았다. GMM 학습도 하지 않았다.
4. 출력되는 0.x ms 'calc time'은 사전 계산된 IK 후보집합 위의 per-frame
   posterior/track selection 시간만 나타낸다. 후보 생성, full pipeline,
   Jetson에서의 실제 runtime은 포함되지 않는다. 이 수치로 E2E 실시간 PASS 금지.
5. 'IK branch switch'를 직접 추적한 것은 아니며 '60도 초과 목표 관절 점프'는
   branch instability의 대용 지표일 뿐이다.
6. 첫 단계 선택/튜닝 및 그리드 해상도 민감도는 탐색적 분석. 본 데이터로 튜닝한 뒤
   동일 데이터에서 통계적인 우월성을 주장하면 안 된다.
7. 동일 q_ref 반복 100회 테스트는 같은 프로세스 내에서만 실행됨.
   전체 R1-R6 canonical 검증을 대체하지 않는다.
8. 기존 P/Pc 로컬 코드는 GitHub에 없으므로 원본 알고리즘과의 성능 우열은 모름.
9. 테스트 원본/결과의 모든 에피소드별 행은 실행 시 생성되는 JSON에 남는다.
   대규모 raw trajectory 데이터는 GitHub에 넣지 않았다.
