I. 사용한 소스 및 공통 조건
-------------------------
- GitHub main NERO analytic IK의 사본: nero_kin.py.
- heldout_ablation.py 및 dynamic_wrist_ablation.py (동일 폴더).
- 모든 방법은 동일한 episode별 입력, feasible IK candidate bank,
  관절 범위, 100Hz discrete update 및 joint speed cap pi rad/s.
- E0: canonical posterior MAP IK, previous-q 무관한 기준해 그대로 추적
- E1: 기준해는 보존, 실제 branch 선택에 joint continuity penalty 적용
- E2: categorical joint candidate probability + entropy-adaptive switching penalty
- E3: E2 후보분포를 시간적 Markov filter와 연계
- 확률은 heuristic/미보정이며, 실제 인간 자세 posterior의 calibration 아님.
- 결과는 초당 15프레임 가상 관측. 센서 이미지, ROS2, 모터 응답, 충돌 없음.
- IC: IK -> FK round-trip: 30/30 random positions, max matrix Frobenius
  error 3.155099787e-7. 행렬 요소는 위치[m]와 무차원 회전이 섞여 있음.

IV. 반드시 지켜야 하는 해석 제한
------------------------------
1. E0~E3는 이번 exploratory 구현이다. 2026-11-14 result.txt의
   실제 P/Pc 코드와 다르며 full 894-trajectory 재검증 결과가 아니다.
2. 고정 손목 실험의 wrist error는 controller가 branch switching으로
   목표 위치에 얼마나 접근하는지 보는 지표임.
3. 'recovery requested jump'는 관절 실행 명령의 즉시 점프가 아니라
   speed cap 이전 목표 IK 각도 사이의 최대 변화. 실제 로봇 충격을
   그대로 나타내지 않는다.
4. 후보 bank 생성 시간/실측 CPU 처리율은 여기서 Jetson 검증되지 않았다.
   온라인 D415+ROS2 실시간성 및 100Hz deadline은 미입증.
5. 잠재적인 노이즈/occlusion model은 합성이고 실제 calibrated 확률
   분포가 아니다. Test data를 통한 후속 튜닝은 별도 held-out set 사용.
6. 관절한계/속도제약만 적용함; 충돌, 가속도/토크 한계, 실물 안전성 미검증.
7. 결과 중 95% CI는 synthetic episode별 paired bootstrap;
   실제 인간 사용자의 subject-level 일반화는 검증하지 않았다.
8. 기술적으로 다른 psi grid에서 IK feasible candidate support도 바뀌므로
   '확률이 항상 유효/무효'와 같은 보편적 결론은 부적절함.
